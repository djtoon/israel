# Israel: The Birth of a Nation — shared contract (lead-maintained)

Game title (renamed 2026-10-12 by the user): **Israel: The Birth of a Nation**. Do not use "Civilization: Israel" in player-facing text (Civilization is a Firaxis/Take-Two trademark); "Civ VI" as the play bar is fine.

Everyone reads this before touching the repo. If you need to change something here, say so in your report; don't silently diverge.

## Scope
- Turn-based Civ VI–style strategy game, Godot 4.7.1, project in `game/`.
- Player leads the State of Israel from **14 May 1948 to 7 October 2023** (changed by the user 2026-10-13; was 2026). One turn = one quarter (3 months), turn 1 = Q2 1948; the last playable turn is Q3 2023 (turn 302). The game then fades to black and shows the user's memorial text for 7 October 2023 (`game/data/ending_oct7.json`, verbatim); that memorial is the only 7 Oct content, and the 2023- Gaza war stays deleted.
- History must be factual, neutral and sourced. Show every affected population accurately (including Palestinian Arabs and neighbouring states). No editorialising; when sources disagree, say so and cite both.

## Bars
- Look: `ref/screenshot.png` (target frame). Terrain must follow `ref/israel_map.webp` (real geography is even better, e.g. SRTM elevation).
- Play: Civilization VI. Notes and real screenshots go in `ref/civ6/`.
- History: published sources. Every event/date/place/number used in game data needs an entry in `sources/SOURCES.md` and a `source` id in the data.
  - A source counts only if someone actually opened it. Each claim's citation carries a live or archived URL (web.archive.org is fine) plus a short verbatim quote, or a page number for print. "accessed: n/a" and "via Wikipedia" do not count as verified.
  - Every casualty or displacement event lists every affected population (Israeli, Palestinian, other), or explicitly says "none reported".
  - Non-historical choices need their own source: a named advocate or a body that proposed that option at the time.
  - `python tools/check_sources.py` must pass before history data ships.
  - Source files:
    - `sources/sources.json` is the master list of S-ids; only the history builder edits it.
    - `sources/SOURCES.md` is GENERATED from `sources.json`. Never hand-append to it, because the next render drops anything added by hand.
    - Map sources live in `sources/map_sources.json`, which the map piece owns, rendered to `sources/MAP_SOURCES.md` with `[MAP:id]` ids.
    - Gameplay sources live in `sources/sim_sources.json` (S500–S699, S750–S799 and S900–S999, reserved for gameplay; the S750+ and S900+ blocks were added for the gap-fork authors, merged from `sources/pending/` by `tools/merge_pending_sources.py`), rendered to `sources/SIM_SOURCES.md`.
    - S-ids are permanent: never renumber or reuse one; retire it with `"retired": true`. Cite history facts by their real S-id. Any mirror must be generated by script, never copied by hand.
    - Any other piece needing a new source asks the history builder (or appends to `sources/requests.jsonl`).
    - `check_sources.py` validates ids across all three files.
    - Events may also cite opened gameplay sources (sim_sources.json entries with url and verbatim quote); allowed from v2 (2026-10-12). City records still use history sources only.
    - Gameplay sources may also use S5000–S5999. `tools/history/apply.py` never mints history ids in that range.

## Tools
- `tools/shot.sh <out.png> [--turns=N] [--frames=N] [--cam=x,z,zoom] [--no-hud]` (`--no-hud` hides all 2D layers; visual critics judge the 3D world in --no-hud frames and the HUD separately) runs the real game windowed and saves a screenshot. The main game node must be in group `"game"` and expose `end_turn()` and `set_camera(x, z, zoom)`.
- `python tools/gen.py image "<prompt>" out.png [--ref img] [--aspect 1:1] [--quality low|medium|high|xhigh] [--transparent]`
- `python tools/gen.py audio "<prompt>" out.mp3 [--seconds 30] [--vocals] [--format mp3_high_quality|wav_cd_quality]` (elevenlabs/music; instrumental by default; see audio_gen.md).
- `python tools/gen.py model in.png out.glb` (image → GLB; tries Hunyuan 3.1 first, which is often out of capacity, then falls back to firtoz/trellis automatically).
- **GPU safety (mandatory).** Launch Godot ONLY through `tools/godot.sh [args]` (or `tools/shot.sh`, which uses it). Never call the Godot exe directly.
  - At most **2 Godot instances at once** (two machine-wide slots; the user's checkpoint PLAY.bat takes one). Extra runs wait.
  - A run only starts while the GPU is below 70°C (nvidia-smi); otherwise it waits to cool. Windowed runs are capped at 30 fps, with a 10 s cooldown.
  - `tools/gpu_watch.sh` (auto-started) logs temperature to `progress/gpu_temp.csv`. At 81°C or above it stops agent-run Godot instances, never the user's game. If your run was killed with "OVERHEAT" in that log, wait and retry; don't work around it. Never delete or create `.godot_gpu.lock*` directories yourself: another piece's run may hold them (2026-10-15, an `rm -rf` of the locks let 3 instances run at once). Stop only your own Godot runs, and let godot.sh clear stale locks.
  - Reason: on 2026-10-11 several parallel windowed Godot instances overheated the GPU and shut the PC down; on 2026-10-14 it crashed again after ~7 min at 84–86°C. Prefer `--headless` (sim tests) and keep windowed runs short; run the full windowed UI suites once at the end of your piece, not repeatedly.
  - Import: `tools/godot.sh --headless --path /c/civ/game --import`. Sim tests: `tools/godot.sh --headless --path /c/civ/game --script res://scripts/sim/sim_test.gd`.
  - Set `GODOT_OWNER=<your piece>`. Take as few screenshots as you need.

## Data files (`game/data/`, JSON, UTF-8). One owner each.
- `map.json`: `{ "cols", "rows", "hex_km", "origin": {lat, lon}, "layout": "pointy-odd-r", "tiles": [ {q, r, lat, lon, terrain, feature, elevation_m, river, coast, region, resource} ... ], "borders": { "<era id>": [[q,r],...] }, "places": [ {name, name_he, q, r, kind} ] }`
  terrain ∈ ocean, coast, lake, grassland, plains, hills, mountains, desert, desert_hills, marsh. feature ∈ none, forest, orchard, wadi, oasis, reef.
- `events.json`: `[ {id, date:"YYYY-MM-DD", turn, title, title_he, summary, kind, places:[...], effects:{...}, choices:[{label, effects}], source:[ids]} ]`
  Also: `cite` (a per-claim list `[{claim, source, quote, url, page?}]`), `affected_populations` (on casualty/displacement events: each group [low,high], "none reported" or "not quantified"), `date_precision`, `date_end`, and choice-level `source`/`cite`. Each choice needs a named advocate.
  cities.json also has: `status[]` (dated control timeline with `cite`), `founded_source`/`founded_cite`, `kind`, `cbs_code`, `population_source`, `lat`, `lon`.
- `cities.json`: `[ {id, name, name_he, q, r, founded:"YYYY or YYYY-MM-DD", population:{"1948":n, "1961":n, ...}, source:[ids]} ]`
- `techs.json`, `civics.json`, `buildings.json`, `units.json`, `districts.json`: owned by the gameplay design piece.

## Code layout (`game/`)
- `scenes/main.tscn` + `scripts/main.gd`: game root (group "game").
- `scripts/map/`: hex math, terrain rendering. `scripts/sim/`: turn engine, yields, cities, research, events. `scripts/ui/`: HUD and panels. `assets/`: images, models, textures, fonts, audio.
- Keep the simulation free of rendering code so turns can be run and tested headless.

## Art conventions (see game/assets/MANIFEST.json, ART_DIRECTION.md)
- Hex-scale models (tiles, units, props): 1.0 = one hex flat-to-flat, +Y up, lowest point at y=0, footprint centred. Units and props face +Z; apply `yaw_fix` from the manifest.
- Metre-scale models (`bld_*`, `lm_*_nb`): 1.0 = 1 m; `real_m` gives the true size.
- Tiles: sink each by its `ground_y`, or use the `*_noplinth` variant.
- Generated GLB materials are forced non-metallic, because a missing metallicFactor renders black in Godot.
- Generated GLBs need normals (`assets/_pipeline/add_normals.py`); without them Godot lights the model as if it faces +Z.
- After replacing a GLB, delete its extracted `<model>_0.png` and `.godot/imported/<model>.glb-*.md5`, or Godot keeps the stale texture.
